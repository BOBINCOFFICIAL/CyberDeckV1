# C# Console Application

This is a basic C# console application scaffolded for development in VS Code on Ubuntu.

## Getting Started

1. Make sure the .NET SDK is installed. If not, follow the official instructions: https://learn.microsoft.com/en-us/dotnet/core/install/linux-ubuntu
2. To build the project:
   ```bash
   dotnet build
   ```
3. To run the project:
   ```bash
   dotnet run
   ```

## Project Structure
- `Program.cs`: Main entry point for the application.
- `MinecraftFlatBot.csproj`: Project file.

## VS Code Extensions
- C# extension (`ms-dotnettools.csharp`) is recommended for best experience.
